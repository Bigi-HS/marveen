# sources/ -- raw input archive

Raw research notes and transcripts, minimally edited, one file per note named
`<date>-<topic>.md`. The curator (Applegate) reads these and writes deduped,
linked entries under `wiki/` (see `../EDITORIAL_GUIDE.md`).

Phase-1 holds only GENERIC PLACEHOLDER examples -- no private content. Real
private source notes are gitignored when they land in phase-2.

- `dominik-research-notes/` -- Dominik's notes (placeholders here).
- `big-ben-archival/` -- video transcripts from the Big Ben pipeline.
- `bond-history/` -- Bond historical context.
